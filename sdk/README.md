# Liberums Kernel ABI SDK

Only public ABI headers from include/abi/, with their original license.
Use -I/path/to/sdk/include. No libc, kernel private header or Aelthuvor is required.
ABI 1.2 and its optional device calls are described in docs/public-abi.md in the source release.
This SDK does not implement an application allocator or runtime.
manifest.json records the source revision and SHA256 of every public header.
