# Linux i386 解释执行

`linux_guest_step()` 从虚拟 EIP 取指，校验整个编码，解码并应用语义。成功后提交虚拟 CPU 状态和指令计数。普通指令推进到下一条，已验证的跳转将 EIP 设为目标。失败保留寄存器、客体内存和计数。Linux 调用的负 errno 是客体结果，该指令仍提交。

| 指令 | 编码范围 |
|---|---|
| MOV | `B8+r` 立即数到 32 位寄存器；`89 /r`、`8B /r` 支持寄存器或绝对 `disp32` 内存 |
| ADD、SUB、CMP | `83 /0`、`83 /5`、`83 /7` 的 32 位寄存器及符号扩展 imm8；`3D` 的 EAX 与 imm32 比较 |
| PUSH、POP | `50+r`、`58+r`，32 位寄存器与专用客体栈 |
| JZ、JNZ、JMP | `74`、`75`、`EB`，有符号 rel8；前两项使用 ZF |
| INT | `CD 80` 进入用户态 Linux 调度器 |

算术更新 CF、PF、AF、ZF、SF、OF。支持范围外的 opcode、前缀、中断和操作数编码返回显式错误。指令超出其段时报告截断；跳转到不可执行目标时报告非法目标。没有 SIB、其他间接寻址、长跳转、浮点或 SIMD 支持。

每次装载的预算为 4096 条已提交指令。运行循环每 32 步调用原生资源撤销检查服务。客体 exit 停止解释器并将状态交还给原生调用者。 [执行器源码](../src/linux_x86.c) · [系统调用语义](linux-syscall-translation.md)
