# Linux 客体内存保护

Phase 3.1 的段记录仍把客体地址映射为原生缓冲区索引。客体拥有 32 KiB 段存储、4 KiB 固定栈。文件最多 32 KiB，每条访存必须完整包含在一个段或栈内。段范围、整数边界、R/W/X 和 W+X 装载限制继续生效。 [客体地址布局](linux-guest-memory.md)

- 取指从同一 EIP 校验整个编码。跨段操作数不会完成解码；从 RW 栈或数据段取指会被拒绝。
- 指令内存访问通过读写接口，绝对内存 MOV 无法向只读段写入。PUSH/POP 的四字节访问只能位于固定客体栈。
- 已采取的跳转验证目标地址的整数范围与 X 权限。预算在 4096 步时停止无退出循环。
- Linux write 在输出前验证整个区间。服务仅收到经校验的原生缓冲区视图。坏地址无法造成部分输出。有效短写可由后端配额或错误产生。
- 虚拟 CPU、段元数据、原生指针、内核资源和实际特权状态均处于客体地址空间之外。解释器消耗字节并执行 C 语义；客体机器码不映射到硬件 EIP。

QEMU/GDB 验证实际原生页表中没有客体段、客体栈、VGA 或资源窗口映射。执行过程中观察到原生输出与撤销检查调用，完成后内核回收域。 [验证记录](phase3-2-validation.md)
