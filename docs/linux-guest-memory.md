# 客体内存

每个客体有 32 KiB 段存储和 4 KiB 客体栈。映像允许地址区间为 `[0x00010000, 0xbff00000)`。栈区间为 `[0xbffff000, 0xc0000000)`。每个 LOAD 记录虚拟起点、大小、存储偏移和 ELF 的 R/W/X 位。段数据在宿主缓冲区紧凑排列，客体地址间的空洞不占存储。栈单独存储，权限为 RW。

读取要求 R，写入要求 W，取指要求 X。单次访问必须非空且完整包含在一个段或栈内。检查地址命中后计算相对偏移，以剩余字节数校验访问长度并拒绝越界。成功后使用原生数组加存储偏移复制数据。越界、未加载和权限错误分别返回状态。客体地址无法索引原生 CPU 状态、原生栈、RAM FS 或设备。

原生演示在 BSS 中保留客体对象。Liberums 仍只映射原生加载器自身的 RX、R、RW 段。客体权限由访问接口逐次检查。原生演示没有申请四页动态资源，也没有获得 VGA 或 PS/2 授权。 [控制范围](phase3-1-feasibility.md) · [QEMU 证据](phase3-1-validation.md)
