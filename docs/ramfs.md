# RAM 文件系统

4 个文件槽保存在 ELF BSS。每个文件容量为 4096 字节，名字最多 63 字节，可用 `file` 或 `/file`。同一文件多次打开时有各自的读写偏移，描述符关闭后可复用。稀疏写或扩展文件会将间隙清零。达到容量边界时可短写，无空闲槽或写入空间时返回 ENOSPC。打开失败不会先创建文件。

`unlink` 立即移除名字。描述符直接关联文件对象，最后一个描述符关闭前，删除的对象仍可通过原有描述符读写并占据一个槽。重用槽时新文件从零长度开始。`rename` 在同域内更新名字，移动已有对象时不复制内容。覆盖目标时，同名的新路径指向源对象，旧目标仍由它的原有描述符引用。无效名字或源文件缺失时，失败的改名不改变对象和描述符。

应用共享同一份域内文件表。返回启动器时可以关闭应用遗漏的文件描述符，仍有名字的文件保留给下一应用。宿主和 QEMU 来宾使用同一组测试覆盖改名、删除、旧描述符读回、槽与描述符复用。QMP 编辑实验从 `/hello.txt` 读取文本并保存修改，后续应用在同一域按路径读取该文件。域回收或虚拟机重启会丢失文件。
