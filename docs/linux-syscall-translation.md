# Linux i386 系统调用翻译

解码器识别 `CD 80` 后调用用户态调度器。编号来自虚拟 EAX，参数来自虚拟寄存器。客体编号和地址不会提交给 Liberums。

| 调用 | 行为 |
|---|---|
| `write(4)` | EBX 为文件描述符，ECX 为客体地址，EDX 为长度。目前只接受 fd 1。先验证完整可读范围，再把已验证的宿主切片交给输出服务。EAX 为服务实际接收的字节数或负 errno |
| `exit(1)` | 取 EBX 的低八位作为退出状态，标记客体结束并将控制交还原生调用者。演示在报告状态后独立退出 Liberums 域 |
| 其他编号 | 在虚拟 EAX 返回 `-ENOSYS`（包括 `read`） |

`write` 对错误描述符返回 `-EBADF`，对不可读、越界、跨段的指针返回 `-EFAULT`。有效 fd 上的零长度调用返回 0。短写返回已接收的字节数。

演示的 fd 1 使用 Liberums 的标量原生 `SYS_LOG_CHAR`，共享每域 128 字符日志配额。配额耗尽返回 `-EAGAIN` 或短写。该接口用 C 字符串传递单字节，遇到 NUL 时返回 `-EIO` 或短写；换行在串口会编码为 CRLF。客体内容位于 `Linux stdout:` 与 `Linux exit` 原生诊断之间。终端、普通 Linux 文件描述符与二进制流的完整语义超出此范围。 [调度器](../src/linux_syscall.c) · [演示服务](../src/linux_exec_main.c)
